# Calculus


A derivada é o cálculo da inclinação de um ponto em uma função qualquer. Existem duas maneiras equivalentes de entender e calcular derivadas: através da **geometria** (visão gráfica com dois pontos) e através da **álgebra** (visão analítica com um ponto).

---

## 1. Intuição Geométrica (Inclinação com 2 Pontos)

Na geometria, olhamos para a "foto ampliada" de um trecho da curva. Para calcular a inclinação, precisamos de uma base e uma altura entre dois locais diferentes.

* **O Conceito:** Escolhemos dois pontos distintos: $(x_1, y_1)$ e $(x_2, y_2)$.
* **A Reta:** Traçamos uma reta **secante** (aquela que corta a curva em dois pontos).
* **O Cálculo:** A inclinação ($m$) é a divisão da subida pelo avanço (a famosa variação):
    $$m = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1}$$



> **Resumo:** Aqui você obtém uma **inclinação média** entre dois momentos.

---

## 2. Intuição Algébrica (Inclinação com 1 Ponto)

Na álgebra, o objetivo é a precisão total. Em vez de uma média entre dois pontos, queremos saber a inclinação **exata** em um único ponto específico.

* **O Conceito:** Fazemos o segundo ponto "escorregar" pela curva até que ele fique infinitamente próximo do primeiro. A distância entre eles tende a zero.
* **A Reta:** A reta deixa de cortar a curva (secante) e passa a apenas encostar nela em um único ponto (reta **tangente**).
* **O Cálculo:** O resultado é a **inclinação instantânea**. É o valor exato de quão inclinada a função está naquele milésimo de segundo.


## 3. Regras de Derivação

Para evitar calcular limites toda vez, usamos **regras de derivação** que já foram provadas matematicamente.

### Regra da Potência 

```
Se f(x) = xⁿ, então f'(x) = n·x^(n-1)

Exemplos:
f(x) = x³     →  f'(x) = 3x²
f(x) = x²     →  f'(x) = 2x
f(x) = x¹     →  f'(x) = 1·x⁰ = 1
f(x) = x⁰     →  f'(x) = 0·x⁻¹ = 0
f(x) = x^(1/2) = √x   →  f'(x) = (1/2)x^(-1/2) = 1/(2√x)
f(x) = x^(-1) = 1/x   →  f'(x) = -1·x^(-2) = -1/x²

Aplicação em pontos específicos:
f(x) = x⁵
f'(x) = 5x⁴
f'(2) = 5(2)⁴ = 5·16 = 80
```


---

### Regra da Constante

```
Se f(x) = c (constante), então f'(x) = 0

Exemplos:
f(x) = 5      →  f'(x) = 0
f(x) = -3.14  →  f'(x) = 0
f(x) = π      →  f'(x) = 0
f(x) = 0      →  f'(x) = 0

Intuição geométrica: Uma constante é uma reta horizontal.
Uma reta horizontal tem inclinação 0.
```

---

### Regra da Multiplicação por Constante

```
Se f(x) = c·u(x) (constante multiplicando uma função), então:
f'(x) = c·u'(x)

Exemplos:
f(x) = 5x²     →  f'(x) = 5·(2x) = 10x
f(x) = -3sin(x) →  f'(x) = -3·cos(x)
f(x) = (1/2)x³  →  f'(x) = (1/2)·(3x²) = (3/2)x²

A constante "sai" da derivada!
```

---

### Regra da Soma e Subtração

```
Se f(x) = u(x) + v(x), então f'(x) = u'(x) + v'(x)
Se f(x) = u(x) - v(x), então f'(x) = u'(x) - v'(x)

Exemplos:
f(x) = x³ + x²
f'(x) = 3x² + 2x

f(x) = 5x² - 3x + 7
f'(x) = 10x - 3 + 0 = 10x - 3

f(x) = sin(x) + cos(x)
f'(x) = cos(x) - sin(x)

Generalização (polinômio completo):
f(x) = 3x⁴ + 2x³ - 5x² + 7x - 3
f'(x) = 12x³ + 6x² - 10x + 7
```

---

### Regra do Produto

```
Se f(x) = u(x)·v(x), então:
f'(x) = u'(x)·v(x) + u(x)·v'(x)

Mnemônico: "Derivada do primeiro vezes o segundo, mais o primeiro vezes a derivada do segundo"

Exemplo 1: f(x) = x²·sin(x)
u(x) = x²      →  u'(x) = 2x
v(x) = sin(x)  →  v'(x) = cos(x)

f'(x) = (2x)·sin(x) + x²·cos(x)
      = 2x·sin(x) + x²·cos(x)

No ponto x = π/2:
f'(π/2) = 2(π/2)·sin(π/2) + (π/2)²·cos(π/2)
        = π·1 + (π/2)²·0
        = π

Exemplo 2: f(x) = (x² + 3)·(x³ + 1)
u(x) = x² + 3     →  u'(x) = 2x
v(x) = x³ + 1     →  v'(x) = 3x²

f'(x) = (2x)·(x³ + 1) + (x² + 3)·(3x²)
      = 2x⁴ + 2x + 3x⁴ + 9x²
      = 5x⁴ + 9x² + 2x
```

---

### Regra do Quociente

```
Se f(x) = u(x) / v(x), então:
f'(x) = [u'(x)·v(x) - u(x)·v'(x)] / [v(x)]²

Mnemônico: "Derivada do numerador vezes denominador, menos numerador vezes derivada do denominador, tudo dividido pelo quadrado do denominador"

Ou: f'(x) = (u'v - uv') / v²

Exemplo 1: f(x) = x² / (x + 1)
u(x) = x²      →  u'(x) = 2x
v(x) = x + 1   →  v'(x) = 1

f'(x) = [2x·(x+1) - x²·1] / (x+1)²
      = [2x² + 2x - x²] / (x+1)²
      = [x² + 2x] / (x+1)²
      = x(x + 2) / (x+1)²

Exemplo 2: f(x) = 1 / x² = x⁻²
u(x) = 1      →  u'(x) = 0
v(x) = x²     →  v'(x) = 2x

f'(x) = [0·x² - 1·2x] / (x²)²
      = [-2x] / x⁴
      = -2/x³
      = -2x⁻³

(Observe: aplicar a regra da potência diretamente daria f'(x) = -2x⁻³, mesmo resultado!)
```

## 4. Regra da Cadeia (Chain Rule)

A **regra da cadeia** é a mais importante e mais poderosa regra de derivação. Ela permite derivar funções compostas (uma função dentro da outra).

### Conceito Básico

Quando temos uma função composta: f(g(x)), usamos a regra da cadeia:

```
Se y = f(g(x)), então:

dy/dx = (dy/dg)·(dg/dx) = f'(g(x))·g'(x)

Ou com notação de prime:
[f(g(x))]' = f'(g(x))·g'(x)

Mnemônico: "Derivada da função externa (mantendo o argumento igual) vezes derivada da função interna"
```

---

### Exemplo 1: f(x) = (x² + 1)³

Aqui temos uma função composta:
- Função externa: g³ (elevar ao cubo)
- Função interna: g = x² + 1

**Método 1: Usando a regra da cadeia**

```
Seja g(x) = x² + 1 (função interna)
Seja f(g) = g³ (função externa)

dg/dx = 2x
df/dg = 3g²

Pela regra da cadeia:
dy/dx = (df/dg)·(dg/dx) = 3g²·2x = 3(x² + 1)²·2x = 6x(x² + 1)²
```

**Verificação (expandir e derivar):**

```
f(x) = (x² + 1)³
     = x⁶ + 3x⁴ + 3x² + 1

f'(x) = 6x⁵ + 12x³ + 6x
      = 6x(x⁴ + 2x² + 1)
      = 6x(x² + 1)²  ✓ Mesmo resultado!
```

---

### Exemplo 2: f(x) = sin(3x)

Função composta:
- Função externa: sin(u)
- Função interna: u = 3x

```
Seja u(x) = 3x
Seja f(u) = sin(u)

du/dx = 3
df/du = cos(u)

Pela regra da cadeia:
df/dx = (df/du)·(du/dx) = cos(u)·3 = 3cos(3x)
```

---

### Exemplo 3: f(x) = e^(2x²)

Função composta:
- Função externa: e^u
- Função interna: u = 2x²

```
Seja u(x) = 2x²
Seja f(u) = e^u

du/dx = 4x
df/du = e^u

Pela regra da cadeia:
df/dx = (df/du)·(du/dx) = e^u·4x = 4x·e^(2x²)
```

---

### Cadeia com Múltiplas Camadas

Quando temos 3 ou mais funções aninhadas, aplicamos a regra da cadeia sucessivamente:

```
Se y = f(g(h(x))), então:
dy/dx = (dy/dg)·(dg/dh)·(dh/dx) = f'(g(h(x)))·g'(h(x))·h'(x)

Exemplo: f(x) = sin(cos(x²))

h(x) = x²           →  dh/dx = 2x
g(h) = cos(h)       →  dg/dh = -sin(h) = -sin(x²)
f(g) = sin(g)       →  df/dg = cos(g) = cos(cos(x²))

Pela regra da cadeia (múltiplas camadas):
df/dx = (df/dg)·(dg/dh)·(dh/dx)
      = cos(cos(x²))·(-sin(x²))·2x
      = -2x·sin(x²)·cos(cos(x²))
```

---

### Regra da Cadeia com Notação de Leibniz (Conceitual)

A regra da cadeia tem uma forma particularmente elegante em notação de Leibniz:

```
Se y = f(u) e u = g(x), então:
dy/dx = (dy/du)·(du/dx)

As frações "se cancelam" conceitualmente:
dy/dx = (dy/du)·(du/dx)

Exemplo numérico:
dy/dx = (3 miles/hour)·(2 hours/day) = 6 miles/day

As "horas" se cancelam, deixando miles/day.
```

## 5. Derivadas de Funções Comuns
Aqui estão as derivadas de funções mais usadas. Podem ser provadas usando a definição de limite ou a regra da cadeia.
 
### Funções Exponenciais e Logarítmicas
 
```
d(e^x)/dx = e^x
 
d(a^x)/dx = a^x·ln(a)    (onde a > 0, a ≠ 1)
 
d(ln(x))/dx = 1/x
 
d(log_a(x))/dx = 1/(x·ln(a))
 
Exemplos:
f(x) = e^(2x)      →  f'(x) = 2e^(2x)  (regra da cadeia)
f(x) = 2^x         →  f'(x) = 2^x·ln(2)
f(x) = ln(x³)      →  f'(x) = (1/x³)·3x² = 3/x  (regra da cadeia)
```
 
---
 
### Funções Trigonométricas
 
```
d(sin(x))/dx = cos(x)
 
d(cos(x))/dx = -sin(x)
 
d(tan(x))/dx = sec²(x) = 1/cos²(x)
 
d(cot(x))/dx = -csc²(x) = -1/sin²(x)
 
d(sec(x))/dx = sec(x)·tan(x)
 
d(csc(x))/dx = -csc(x)·cot(x)
 
Exemplos:
f(x) = sin(3x)     →  f'(x) = 3cos(3x)   (regra da cadeia)
f(x) = cos(x²)     →  f'(x) = -sin(x²)·2x = -2x·sin(x²)
f(x) = tan(x)      →  f'(x) = sec²(x)
```
 
---
 
### Funções Trigonométricas Inversas
 
```
d(arcsin(x))/dx = 1/√(1 - x²)
 
d(arccos(x))/dx = -1/√(1 - x²)
 
d(arctan(x))/dx = 1/(1 + x²)
 
d(arccot(x))/dx = -1/(1 + x²)
 
Exemplos:
f(x) = arcsin(2x)   →  f'(x) = 1/√(1 - 4x²)·2 = 2/√(1 - 4x²)  (regra da cadeia)
f(x) = arctan(x²)   →  f'(x) = 1/(1 + x⁴)·2x = 2x/(1 + x⁴)
```
 
---
 
### Funções Hiperbólicas
 
```
d(sinh(x))/dx = cosh(x)
 
d(cosh(x))/dx = sinh(x)
 
d(tanh(x))/dx = sech²(x) = 1/cosh²(x)
 
Exemplos:
f(x) = sinh(x)     →  f'(x) = cosh(x)
f(x) = cosh(2x)    →  f'(x) = 2sinh(2x)
```

## 6. Derivadas de Ordem Superior

Uma **derivada de ordem superior** é a derivada da derivada (ou da derivada da derivada, etc.).

### Segunda Derivada

A **segunda derivada** é a derivada da primeira derivada:

```
Notação:
f''(x) ou d²f/dx² (Leibniz)
ḟ (Newton, para derivadas em relação ao tempo)

Significa: derivar duas vezes

Exemplo: f(x) = x⁴ + 2x³ - 5x²

Primeira derivada:
f'(x) = 4x³ + 6x² - 10x

Segunda derivada (derivar f'(x)):
f''(x) = 12x² + 12x - 10

Num ponto específico x = 1:
f''(1) = 12(1)² + 12(1) - 10 = 12 + 12 - 10 = 14
```

---

### Interpretação Geométrica da Segunda Derivada

```
f'(x): inclinação da curva (taxa de mudança de f)
f''(x): curvatura (taxa de mudança de f')

f''(x) > 0: curva é côncava para cima (∪)
f''(x) < 0: curva é côncava para baixo (∩)
f''(x) = 0: ponto de inflexão

Exemplo: f(x) = x²
f'(x) = 2x (inclinação aumenta com x)
f''(x) = 2 > 0 (sempre côncava para cima)

Geometricamente:
     ╱╲
    ╱  ╲  ← Côncava para cima
   ╱    ╲
```

---

### Terceira Derivada e Superiores

```
Terceira derivada: f'''(x) = d³f/dx³

Quarta derivada: f''''(x) = d⁴f/dx⁴

E assim por diante...

Exemplo: f(x) = x⁵ + 3x⁴ - 2x³

f'(x) = 5x⁴ + 12x³ - 6x²
f''(x) = 20x³ + 36x² - 12x
f'''(x) = 60x² + 72x - 12
f''''(x) = 120x + 72
f'''''(x) = 120
f''''''(x) = 0 (e todas as seguintes são 0)
```

---

### Polinômio de Taylor

A segunda (e derivadas superiores) permitem aproximar funções por polinômios:

```
Aproximação de Taylor em torno de x = a:

f(x) ≈ f(a) + f'(a)(x-a) + [f''(a)/2!](x-a)² + [f'''(a)/3!](x-a)³ + ...

Ordem 1 (linear):
f(x) ≈ f(a) + f'(a)(x-a)

Ordem 2 (quadrática):
f(x) ≈ f(a) + f'(a)(x-a) + [f''(a)/2](x-a)²

Exemplo: Aproximar f(x) = sin(x) em torno de x = 0

f(0) = sin(0) = 0
f'(x) = cos(x)  →  f'(0) = 1
f''(x) = -sin(x) →  f''(0) = 0
f'''(x) = -cos(x) →  f'''(0) = -1

Aproximação (até terceira ordem):
sin(x) ≈ 0 + 1·(x-0) + (0/2)(x-0)² + (-1/6)(x-0)³
sin(x) ≈ x - x³/6

Verificação:
sin(0.1) ≈ 0.1 - (0.1)³/6 ≈ 0.1 - 0.000167 ≈ 0.0998
sin(0.1) = 0.0998...  Muito próximo!
```
