# 5. Preprocessing Steps (Execution Order)

## Data Cleaning
- Rename columns
- Drop constant features
- Drop redundant features
- Handle missing values (impute/remove)
- Remove duplicates
- Fix wrong/impossible data

---

## Data Engineering
- Feature engineering (new features)
- Skew treatment
- Outlier handling
- Encoding (categorical → numeric)
- Scaling

---

## Train/Test Split
- Split data
- Stratify if needed

---

## Post-Split (IMPORTANT)
- Fit transformers only on train
- Apply transformations to test

---

## Class Imbalance
- Apply SMOTE (only on train)
- Or use class weights

---

## Data Tunning
- Feature selection
- Dimensionality reduction

---

##  Notes
- No data leakage
- SMOTE only on train
- Discretization/Binarization → only if redefining problem
