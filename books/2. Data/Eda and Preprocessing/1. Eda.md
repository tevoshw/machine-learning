# Exploratory Data Analysis (EDA)

## Data Overview
The goal here is to understand the data. In many cases, we receive a dataset without context, only with a problem to solve. Therefore, we must first understand its structure and what it represents.

### Shape
**The shape of a dataset refers to its structural dimensions, representing the number of elements along each axis (rows, columns, and higher dimensions)**

`.shape` returns the shape of dataframe in (rows, columns)

### Data Types
**While Python has standard types like int, float, and str, libraries like NumPy and Pandas use more specific types to optimize memory and processing speed. The data type tells the computer how to interpret the binary stored in memory—whether it should treat a value as a number to be added, a category to be grouped, or a date to be sequenced.**

`.dtypes` for all the dataste and `.dtype` for a single on column

### Data Samples 
**A sample (also known as an observation, record, or instance) represents a single unit of data in your collection. In a standard 2D dataset, each row is a sample, while each column represents a feature (a characteristic of that sample). For example, in your "Drugs Project," a single sample would represent one specific patient, including their age, sex, and the drug they were prescribed.**

`.head()` View the first N samples

`.tail()` View the last N samples

### Column Names
**Column names provide the essential mapping between raw data and human-readable features. In Machine Learning, these names represent your Independent Variables (features like Age, BMI, or Blood_Pressure) and your Dependent Variable (the Target or Label you want to predict, like Drug_Type). Clear and consistent naming is the first step in successful data cleaning, as it allows you to select, filter, and manipulate specific data points without confusion.**

`.columns()`

## Data Quality Check
After an initial inspection, we move to identifying issues that may distort the dataset, mislead the analysis, or negatively impact the model.

> Always ask yourself: "Can I trust this data?"

### Constant Features
**A Constant Feature is a column in your dataset where every single row contains the exact same value. In terms of information theory, these features have zero variance. Because they do not change, they provide no predictive power—they cannot help a Machine Learning model distinguish between different classes (like different types of drugs) because the value is the same for every patient**
1. `.nunique()` Shows the differents values that a feature have
2. `VarianceThreshold` (From SKLearn) Show the variance of values in the features

### Redundant Features
**A redundant feature occurs when two or more columns in your dataset provide the same information to the machine learning model, even if the data are not identical**
1. `.corr()` A correlation between all the features, show the values for how mush each feature contribute for other feature

### Missing Values (Nulls)
**Null values refer to the absence of data for one or more features in a specific observation**
1. `.isnull()` Show how values are missing in each features
2. `df.info()` Show all the informations about the features, it can also be a good helper to find missing values for the first view

### Duplicated Data
**Duplicates are identical rows that provide no new information to your Machine Learning model. If left untreated, they can "weight" certain patterns too heavily, leading the model to believe a specific combination of features (like Age=40 and Drug=DrugA) is more common than it actually is. This results in Overfitting, where the model is simply memorizing repeated rows rather than learning general rules**

1. `.duplicated()` Show all the samples that are exactly the same, or duplicateds

### Cardinality
**Cardinality is a measure of the "uniqueness" of the data in a column. When a categorical feature has many different labels, we call it High Cardinality. For example, a Country column has high cardinality (nearly 200 possible values), while a Gender column has Low Cardinality (typically 2 or 3 values)**

1. `.nunique()` Show all the differents values in a feature
2. `.barplot()` Plot graphs with the values for each features


### Outliers
**An outlier is a data point that is located at an abnormal distance from other values in a random sample from a population. They are important because they can heavily skew your statistical measures (like the Mean) and lead to poor model performance, especially in algorithms sensitive to distance (like Linear Regression or KNN)**

1. `.boxplot()` Shows a graph with outliers in points form
2. `.scatterplot()` Show a graph with all the point, in this case the analyze of outliers it's from us


### Wrong or Impossible Data
- **Unit Inconsistency**
This happens when data is collected from different sources using different scales.
    1. `.histplots()` A histogram graph

- **Censoring**
Censoring occurs when you have some information about a value, but you don't know its exact measurement because of some limitation.
    1. `.histplots()` A histogram graph, that we can see if the tail of the last bin are too big or something related to that problem

- **Data Entry**
Categorical data is often messy due to human error (Example: Gender column containing "Male", "male", "M", and "  Male  ".)
    1. `.unique()`

- **Negative values**
    1. `df[df[feature] < 0]`

## STRUCTURE AND QUALITY OF THE FEATURES
**CONSTANT FEATURE**

2. `.value_counts()`

**REDUNDANT FEATURE**
- DEFINITION: Are more than one feature which contains the same data in a different way.

- HOW TREAT:
1. Analyses and choose the feature who it's more advantageous, and remove the other, or just maintain  both

**DUPLICATES**
- DEFINITION: Are repeated samples, here's the problem are rows and not the features
- CHARACTERISTICS: Can be all the fatures repeated, or some only
- EXAMPLE: SAMPLE 1: 1, 2, 3, 4 // SAMPLE 2: 1, 2, 3, 4 (all the features) // SAMPLE 3: 1,2,2,4 (some only)
- HOW FIND:
1. `.duplicated()`
- HOW TREAT:
1. `.drop_duplicated()`

**CARDINALITY** 
- DEFINITION: A feature with high quantity of differents labels or targets (it's much more common in categorial features)

## MISSING & INVALID DATA
**NULL VALUES**
- DEFINITION: Are missing values in the dataset.
- CHARACTERISTICS: The null valeus isn't a 0, or '' string, just doens't exist like a ghost value
- EXAMPLE: 5 features: 1, 2, 3, ,5 (one feature is missing)
- HOW FIND:
1. .isnull()
- HOW TREAT:
1. IMPUTATION (FILL): `SimpleInputer(strategy = '')`
2. REMOVE: `.dropna`

**NEGATIVE DATA**
- DEFINITION: Features with negatives values.
- CHARACTERISTICS: 
1. Not necessarily an error, in some case are (it makese sense un real life?)
2. Can be VALID (weather, profit, variaton and more) or INVALID (error)
- EXAMPLE: Weather = -48 (valid) // Age = -39 (invalid)
- HOW  FIND:
1. `(data < 0).sum().sum()`
- HOW TREAT:
1. REMOVE: `.query('column >= 0')`

**CENSORING**
- DEFINITION: When the value of a measurement or observation is restricted at a certain threshold, masking the true underlying value.
- CHARACTERISTICS:
1. The "Ceiling" Effect: Data points accumulate in a straight line at the maximum or minimum limit (as seen in your Regplot at 500k).
- TYPES:
1. Right-Censoring: The limit is at the top. (Ex: Surveys where the highest option is "Income > $100k").
2. Left-Censoring: The limit is at the bottom. (Ex: A chemical test that cannot detect substances below 0.01mg).
- EXAMPLES:
1. Housing: Prices capped at $500,000 for privacy or system limits (VALID but restricted).
2. Visual: A horizontal "wall" of dots at the edge of a Scatter Plot.
- HOW FIND: 
1. HISTOGRAMS: `.hist()`
- HOW TREAT:
1.  Flagging
2. Tobit model
