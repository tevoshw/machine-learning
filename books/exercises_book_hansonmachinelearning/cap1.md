### EXERCISES CHAPTER 1

- Como vocẽ definiria machine learning? Uma área da ciẽncia que foca na resolução de problemas com a autocapacidade de aprendizado por parte das máquinas

- Você consegue apontar quatros tipos de problemas que se destacam? APRENDIZADO supervisionado, não-supervisionado, semisupervisionado e por reforço

- O que é um conjunto de treinamento modulado? Um conjunto que possui labels, uma coluna (feature) que possui as "respostas" dos dados, como números ou classes

- Quais são as duas tarefas supervisonadas mais comuns? Regressão  (números) e Classficação (classes)

- Você consegue citar 4 tarefas comuns não-supervisionadas? Clusterização, detecção de anomalias, aprendizado por regras e visualização da dimensionalidade

- Qual tipo de algoritmo que você usaria para possibilitar um robo andasse por ai em lugares inexplorados? Por reforço

- Qual tipo de algoritmo você segmentaria seus clientes em grupo? Clusterização (K-MEANS)

- Detecção de spam é supervisionado ou não supervisionado? Pode ser de ambos, porém sendo mais comum no supervisonado

- O que é um sistema de aprendizado online? Um sistema que quando recebe novos dados, apenas incrementa eles e não é necessário um treinamento em dados antigos com os novos (somente os novos são treinados)

- O que é o aprendizado out-of-core? É um modelo que utiliza apenas a memória necessária para o aprendizado

- Qual o tipo de algoritmo que utiliza semelhança de similaridade para efetuar predições? KNN

- Qual a diferença de paramẽtro e hiperparametro? Um é definido e atualizado durante o treinamento e quem faz isso é o próprio modelo (parametro), já hiperparametro é definido por dev e não é atualizado com o treino

- Para que servem os algoritmos de modelo? E como eles fazem a predição? Eles são modelos que utilizam de retas, e da matemática para fazerem as predições e não por similaridade, e eles servem para obter melhores médias em alguns tipos de problemas e dados

- Mencione 4 dos principais desafios de ml? Under e overfitting, ajustes incorretos de hiperparametros, incompatibilidade de dados e etc

- Caso o modelo tenha um bom desempenho no treino, mas com novos dados seja ruim o que aconteceu? Ele não generaliza tão bem, e pode ter ocorrido um overfitting ou uma incompatibilidade nos dados

- O que é um conjunto de teste? e porque utilizamos? Ele é um parte splitada do dataset utilizada para verificar o desempenho do modelo antes de subir para produção

- Qual o propósito de um conjunto de validação? È validar os novos dados com o desempenho do modelos criados, escolhendo assim o melhor modelo

- o que é um train-dev-set e quando é necessário? Train-dev-set é uma parte splitada dos dados de treino que é utilizado para encontrar erros e verificar anomalias e é utilizado quando o modelo utiliza dados x, e testamos com dados y

- O que pode sair errado se você ajustar os hiperparametros utilizando os dados de testes? O modelo pode generalizar pouco com os dados que possui, e quando utilizado já pronto, pode dar predições erradas
