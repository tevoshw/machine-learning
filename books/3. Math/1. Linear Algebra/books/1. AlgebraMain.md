the root stone of all linear algebra.

**Computing Interpretation:**
Vectors can only be added or subtracted if they have the **same shape**.

```
v₁ = [1]    v₂ = [3]    v₁ + v₂ = [1+3]   = [4]

     [3]         [5]                [3+5]     [8]

Shape: (3,) + (3,) = (3,)  ✓ Valid


---------------------------------------------------

v₁ = [1]    v₂ = [3]    v₁ + v₂ = INVALID
     [2]         [4]
     [3]         [5]
              [6]

Shape: (3,) + (4,) Incompatible
```

#### 1.2 **Scalar Multiplication**
 Here we multiply all the vector for a number. Scalar multiplication scales the vector. c > 1 makes it longer, 0 < c < 1 makes it shorter, negative c reverses direction.

**Geometric interpretation:** 
For a better visualization: https://www.universalclass.com/articles/math/pre-calculus/how-to-multiply-vectors-scalar-dot-product.htm

Here we can increase, decrease, rotate and rotate the arrow representing the vector

---
**Computing Interpretation:**


Multiply each element of a vector by a single number (scalar).

```
v = [1]     scalar c = 2     c·v = [2·1]   = [2]
    [2]                           [2·2]     [4]
    [3]                           [2·3]     [6]

Shape: (scalar) × (3,) = (3,)
```


---

#### 3. **Dot Product (Inner Product)**

Multiply corresponding elements of two vectors and sum them all. **Only works for vectors of the same shape.**

```
v₁ = [1]    v₂ = [3]    v₁ · v₂ = (1×3) + (2×4) + (3×5)
     [2]         [4]              = 3 + 8 + 15
     [3]         [5]              = 26

Shape: (3,) · (3,) = scalar (single number)

Formula: v₁ · v₂ = Σ(v₁ᵢ × v₂ᵢ)
```

**Properties:**
- Result is always a single number (scalar)
- **Commutative:** v₁ · v₂ = v₂ · v₁
- Measures similarity: dot product = 0 means perpendicular vectors

**Geometric interpretation:** The dot product measures how much two vectors point in the same direction. High positive value = similar direction. Zero = perpendicular. Negative = opposite directions.

**In ML:** Used in neural networks for weight calculations, similarity metrics, and attention mechanisms.

---

#### 4. **Vector Norm (Magnitude)**

The "length" or "size" of a vector.

```
Euclidean Norm (L2): ||v|| = √(v₁² + v₂² + v₃² + ...)

v = [3]    ||v|| = √(3² + 4²) = √(9 + 16) = √25 = 5
    [4]
```

**Other norms:**
```
L1 Norm (Manhattan):  ||v||₁ = |v₁| + |v₂| + |v₃| + ...
                      Example: |3| + |4| = 7

L∞ Norm (Maximum):    ||v||∞ = max(|v₁|, |v₂|, |v₃|, ...)
                      Example: max(3, 4) = 4
```

**In ML:** Norms are used for:
- Regularization (L1, L2 penalties in loss functions)
- Normalization of vectors
- Distance metrics

---

#### 5. **Vector Normalization**

Convert a vector to unit length (norm = 1) while keeping direction.

```
v = [3]    ||v|| = 5    û = v / ||v|| = [3/5]   = [0.6]
    [4]                            [4/5]     [0.8]

Check: ||û|| = √(0.6² + 0.8²) = √(0.36 + 0.64) = √1 = 1 ✓
```

**In ML:** Normalization ensures all vectors have the same scale, improving model stability and training speed.

## Terminology Clarification: "Dot Product" vs "Matrix Multiplication"

This is a common source of confusion! Here's the exact relationship:

### **Dot Product** (Inner Product)
- **Operates on:** Two vectors
- **Result:** A scalar (single number)
- **Formula:** v₁ · v₂ = Σ(v₁ᵢ × v₂ᵢ)
- **Example:** [1,2,3] · [4,5,6] = 32

### **Matrix Multiplication**
- **Operates on:** Two matrices
- **Result:** A matrix
- **Core operation:** Multiple dot products performed systematically
- **Example:** (m×n) × (n×p) = (m×p) matrix

### **The Connection**

Matrix multiplication **is** dot product applied to all row-column pairs:

```
A × B:
- Take row i from A (a vector)
- Take column j from B (a vector)
- Compute their dot product
- Place result in position C[i,j]

This process repeats for all i,j combinations.
```

### **Terminology Usage**

| Context | Term Used | What It Means |
|---------|-----------|---------------|
| **Linear Algebra** | Dot Product | Vector × Vector → scalar |
| **Linear Algebra** | Matrix Multiplication | Matrix × Matrix → matrix |
| **Machine Learning** | Dot Product | Often used for both (loosely) |
| **NumPy/TensorFlow** | `dot()` or `@` | Could be vector or matrix depending on inputs |
| **Neural Networks** | "Computing the dot product" | Usually means matrix multiplication (weights × inputs) |

**In practice:** Most engineers and data scientists use "dot product" and "matrix multiplication" somewhat interchangeably when context is clear, but technically:
- **Dot product** = vector operation
- **Matrix multiplication** = extends dot product to matrices

### What is a Matrix?

A **matrix** is a 2D array of numbers arranged in rows and columns.

```
Matrix M = [1  2  3]
           [4  5  6]

Shape: (2, 3)  →  2 rows, 3 columns
```

In machine learning:
- **Images:** Matrix of pixel values
- **Weights:** Neural network parameters
- **Data batches:** Multiple samples stacked as rows
- **Covariance matrices:** Relationships between features

---

### Matrix Operations

#### 1. **Matrix Addition / Subtraction**

Matrices can only be added or subtracted if they have the **exact same shape**.

```
A = [1  2]    B = [5  6]    A + B = [1+5   2+6]   = [6   8]
    [3  4]        [7  8]            [3+7   4+8]     [10  12]

Shape: (2,2) + (2,2) = (2,2)  ✓ Valid

A = [1  2]    B = [5  6]    A + B = ❌ INVALID
    [3  4]        [7  8]
                  [9  10]

Shape: (2,2) + (3,2) ❌ Incompatible
```

---

#### 2. **Scalar Multiplication**

Multiply each element by a scalar.

```
M = [1  2]    scalar c = 3    c·M = [3   6]
    [3  4]                          [9  12]
```

---

#### 3. **Matrix Multiplication (Dot Product)**

Multiply two matrices to get a new matrix using **dot products**. **STRICT SHAPE RULES!**

The number of **columns in the first matrix** must equal the number of **rows in the second matrix**. Each element of the result is a **dot product** between a row and a column.

```
A (shape: m × n)  ×  B (shape: n × p)  =  C (shape: m × p)

HOW IT WORKS:
Matrix multiplication = Series of dot products
- Take row i from A (this is a vector)
- Take column j from B (this is a vector)  
- Compute their DOT PRODUCT
- Place result in C[i,j]
- Repeat for all row-column pairs

C[i,j] = Row_i(A) · Column_j(B)
```

**How it works:**

```
A = [1  2  3]    B = [4   5]     C = A × B = [?  ?]
    [4  5  6]        [7   8]                 [?  ?]
                     [9  10]

A shape: (2, 3)
B shape: (3, 2)
C shape: (2, 2)  ✓ Valid: 3 = 3

Computing each element as a DOT PRODUCT:

C[0,0] = Row 0 of A · Column 0 of B
       = [1, 2, 3] · [4, 7, 9]  (dot product of vectors!)
       = (1×4) + (2×7) + (3×9) = 4 + 14 + 27 = 45

C[0,1] = Row 0 of A · Column 1 of B
       = [1, 2, 3] · [5, 8, 10]
       = (1×5) + (2×8) + (3×10) = 5 + 16 + 30 = 51

C[1,0] = Row 1 of A · Column 0 of B
       = [4, 5, 6] · [4, 7, 9]
       = (4×4) + (5×7) + (6×9) = 16 + 35 + 54 = 105

C[1,1] = Row 1 of A · Column 1 of B
       = [4, 5, 6] · [5, 8, 10]
       = (4×5) + (5×8) + (6×10) = 20 + 40 + 60 = 120

Result: C = [45   51]
            [105  120]
```

**Visual representation of dot product in matrix multiplication:**

```
A = [1  2  3]    B = [4   5]
    [4  5  6]        [7   8]
                     [9  10]

Row 1 of A: [1, 2, 3] (this is a VECTOR)
Col 1 of B: [4, 7, 9] (this is a VECTOR)

Dot product: [1,2,3]·[4,7,9] = 45  → C[0,0]

Each element of C is computed as a vector dot product!
```

**Shape Rule Visualization:**

```
(m × n)  ×  (n × p)  =  (m × p)
 ↓ inner dimensions must match (n = n) ↓
```

**The relationship between Dot Product and Matrix Multiplication:**

```
Matrix multiplication IS dot product applied systematically:

Vector · Vector = Scalar (single value)
[1,2,3] · [4,5,6] = 1×4 + 2×5 + 3×6 = 32

Matrix × Matrix = Multiple dot products
- Each row of A is a vector
- Each column of B is a vector
- Each cell C[i,j] = Row i of A · Column j of B

Formula:
C[i,j] = Σ(A[i,k] × B[k,j])  for k = 0 to n-1

This is exactly the dot product formula!
```

**Key Properties:**
- **NOT commutative:** A × B ≠ B × A
- **Associative:** (A × B) × C = A × (B × C)
- **Distributive:** A × (B + C) = (A × B) + (A × C)

**In ML:** The most fundamental operation:
- Forward pass: output = weights × input
- Neural network layers: hidden = activation(W × x + b)
- Batch processing: multiple samples at once

---

#### 4. **Matrix Transpose**

Flip rows and columns.

```
A = [1  2  3]    A^T = [1  4]
    [4  5  6]           [2  5]
                         [3  6]

Shape: (2, 3)  →  (3, 2)

Element-wise: A[i,j] = A^T[j,i]
```

**Properties:**
- (A^T)^T = A
- (A × B)^T = B^T × A^T (note the reverse order!)
- (A + B)^T = A^T + B^T

**In ML:**
- Reshaping data for different operations
- Computing correlations and covariances
- Simplifying mathematical expressions

---

#### 5. **Matrix Inverse**

For square matrices only (m = n). The inverse A⁻¹ satisfies: **A × A⁻¹ = I** (identity matrix)

```
A = [1  2]    A⁻¹ = [2   -1]
    [1  3]           [-1/2  1/2]

Check: A × A⁻¹ = [1  0]  (Identity matrix I)
                  [0  1]
```

**Important:** Not all matrices have inverses. A matrix must be:
- **Square** (same number of rows and columns)
- **Non-singular** (determinant ≠ 0)

**In ML:**
- Solving linear systems: if Ax = b, then x = A⁻¹b
- Computing analytical solutions for linear regression
- Not commonly used in modern deep learning (too computationally expensive)

---

#### 6. **Element-wise Multiplication (Hadamard Product)**

Multiply corresponding elements. Different from matrix multiplication!

```
A = [1  2]    B = [3  4]    A ⊙ B = [1×3   2×4]   = [3   8]
    [5  6]        [7  8]             [5×7   6×8]     [35  48]

Same shape required: (2,2) ⊙ (2,2) = (2,2)
```

**vs Matrix Multiplication:**
```
A × B (normal):        A ⊙ B (element-wise):
[1  2]   [3  4]        [1  2]   [3  4]       [3   8]
[5  6] × [7  8]   vs   [5  6] ⊙ [7  8]    =  [35  48]

= [1×3+2×7   1×4+2×8]   (dot products)
  [5×3+6×7   5×4+6×8]

= [17  20]
  [57  68]
```

**In ML:** Used for:
- Applying masks to tensors
- Applying activation functions element-wise
- Attention mechanisms

## Part 3: Tensors

### What is a Tensor?

A **tensor** is a generalization of vectors and matrices to any number of dimensions.

```
Scalar (rank-0):       5
                       Shape: ()

Vector (rank-1):       [1, 2, 3]
                       Shape: (3,)

Matrix (rank-2):       [[1, 2], [3, 4]]
                       Shape: (2, 2)

Tensor (rank-3):       [[[1, 2], [3, 4]], [[5, 6], [7, 8]]]
                       Shape: (2, 2, 2)

Tensor (rank-4):       Batch of images
                       Shape: (batch_size, height, width, channels)
                       Example: (32, 224, 224, 3)
```

---

### Tensor Operations

#### 1. **Tensor Addition / Subtraction**

Same shape required.

```
T₁ shape: (2, 3, 4)
T₂ shape: (2, 3, 4)
T₁ + T₂ shape: (2, 3, 4)  ✓ Valid

T₁ shape: (2, 3, 4)
T₂ shape: (2, 3, 5)
T₁ + T₂ = ❌ INVALID
```

---

#### 2. **Scalar Multiplication**

```
T shape: (2, 3, 4)
c = 5
c × T shape: (2, 3, 4)  ✓ Valid
```

---

#### 3. **Tensor Multiplication (Batched Matrix Multiplication)**

Apply matrix multiplication to multiple matrices at once. Very common in deep learning!

```
A shape: (batch_size, m, n)  ×  B shape: (batch_size, n, p)
Result shape: (batch_size, m, p)

Example: Process 32 samples simultaneously
A shape: (32, 5, 10)    ×    B shape: (32, 10, 3)
Result shape: (32, 5, 3)

Each of the 32 samples follows normal matrix multiplication rules.
```

**In ML:** Essential for:
- Processing batches of data
- Efficient GPU computation
- Neural networks with batch processing

---

#### 4. **Tensor Contraction (Generalized Matrix Multiplication)**

Multiply along specified dimensions.

```
Example: Image batch (32, 224, 224, 3) × Weights (3, 64)
Along the channel dimension (3), perform matrix multiplication

Result: (32, 224, 224, 64)

Each pixel's 3-channel value is multiplied by the weight matrix.
```

---

#### 5. **Broadcasting**

Automatically expand tensors to compatible shapes for operations.

```
Tensor A shape: (3, 4)
Tensor B shape: (4,)

Broadcasting expands B to (3, 4):
B → [b₀  b₁  b₂  b₃]
     [b₀  b₁  b₂  b₃]
     [b₀  b₁  b₂  b₃]

A + B is now valid!

Rules:
1. Dimensions are compared from right to left
2. Dimensions are compatible if they're equal or one is 1
3. Missing dimensions are added on the left

Example:
(5, 4, 3) + (3,) → (5, 4, 3) + (1, 1, 3) → (5, 4, 3)  ✓
(5, 4, 3) + (2,) → ❌ INVALID (3 ≠ 2)
```

**In ML:** Broadcasting is used constantly:
- Adding biases to weights: (n_samples, n_features) + (n_features,)
- Normalizing batches: subtract mean from each sample
- Scaling layers: multiply by scale factor

---

#### 6. **Reshaping**

Change tensor shape without changing data.

```
T shape: (2, 3, 4)  →  Reshape to (6, 4)  →  Reshape to (24,)

Total elements unchanged: 2 × 3 × 4 = 6 × 4 = 24 ✓

Flatten example:
[[[1, 2], [3, 4]],
 [[5, 6], [7, 8]]]

Flatten to: [1, 2, 3, 4, 5, 6, 7, 8]
```

**In ML:**
- Flattening CNN outputs to feed into dense layers
- Reshaping batches for different operations
- Preparing data for processing

---

#### 7. **Transpose for Tensors**

Permute axes in any order.

```
T shape: (2, 3, 4)

Transpose axes (0, 2, 1): (2, 4, 3)
Transpose axes (2, 0, 1): (4, 2, 3)
Transpose axes (1, 0, 2): (3, 2, 4)

Example: Swap last two dimensions
(batch, height, width, channels) → (batch, height, channels, width)
```


## Common Pitfalls

### 1. **Shape Mismatch in Matrix Multiplication**

```
WRONG:
A shape: (3, 4)  ×  B shape: (3, 5)
         4 ≠ 3  → ❌ ERROR

CORRECT:
A shape: (3, 4)  ×  B shape: (4, 5)
         4 = 4  → ✓ Result: (3, 5)
```

### 2. **Forgetting Matrix Multiplication is NOT Commutative**

```
A × B ≠ B × A (in general)

Example:
A = [1  0]    B = [0  1]
    [0  2]        [1  0]

A × B = [0  1]    B × A = [0  2]
        [2  0]            [1  0]

Different results!
```

### 3. **Adding Matrices of Different Shapes**

```
WRONG:
A shape: (3, 4)  +  B shape: (4, 3)
❌ ERROR

CORRECT: Transpose first
A^T shape: (4, 3)  +  B shape: (4, 3)
✓ Result: (4, 3)
```

### 4. **Confusing Element-wise vs Matrix Multiplication**

```
Element-wise (⊙):  Same shape, multiply corresponding elements
Matrix mult. (×):  (m,n) × (n,p), compute dot products

They give VERY different results!
```
