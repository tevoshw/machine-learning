## 3. T (Target weight (y))

````
T = [20]    
     [21]

````


## 4. Dot Product (X · w)

For the multiplication to work:

- X has shape (3,4)
- W has shape (4,1)

Rule: 
1. The number of columns in X must match the number of rows in w -> (a,b) (n,m) b == n
2. The operation gonna create a new vectoer with the (a,m) shape 

So:

(3,4) · (4,1) = (3,1)

That we gonna call $ŷ$, and have the values for our predictions for that iteration. We compute row by row:

```


[[1 2  3  4]				[[1]
[4  5  6  7]  			. 	 [2]
[7  8  9 10]]				 [3]
							 [4]]
X(3,4)						W(4,1) 


Row 1:
[1  2  3  4] · [1 2 3 4]  
= (1×1) + (2×2) + (3×3) + (4×4)  
= 1 + 4 + 9 + 16 = 30  

Row 2:
[4  5  6  7] · [1 2 3 4]  
= (4×1) + (5×2) + (6×3) + (7×4)  
= 4 + 10 + 18 + 28 = 60  

Row 3:
[7  8  9 10] · [1 2 3 4]  
= (7×1) + (8×2) + (9×3) + (10×4)  
= 7 + 16 + 27 + 40 = 90  


ŷ = [[30]
	 [60]
	 [90]]

	(3,1)
```


## 6. Subtraction with T (target vector)

Now we compute:

$error = ŷ - y$

That means we gonna subtract two vectors, and their need to have the same shape to this operations occurs. So how both have (3,1), we can do. And again gonna create a new vector that we gonna call $ERROR$

```
T = [20]    
     [21]         
     [19] 

     (3,1)

ŷ = [[30]

error (ŷ-T) = [[30 - 20]   ->  	error = [[10]
		[60 - 21]					[39]

```
