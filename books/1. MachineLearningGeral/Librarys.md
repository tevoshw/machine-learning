# Libraries Used in This Project

This repository uses some of the most important and widely adopted **Python libraries for Data Science and Machine Learning**. Each library has a specific role in the ML pipeline, from data manipulation to model training and visualization.

---

## NumPy

### What it is
**NumPy (Numerical Python)** is the foundational library for numerical computing in Python.

### Why it is used
- Efficient multi-dimensional arrays (`ndarray`)
- Fast mathematical and linear algebra operations
- Base dependency for almost all ML libraries

### Common use cases
- Handling vectors and matrices
- Feature scaling and transformations
- Implementing mathematical operations for ML algorithms

---

## Pandas

### What it is
**Pandas** is a data manipulation and analysis library built on top of NumPy.

### Why it is used
- Easy handling of structured data (tables, CSVs, Excel files)
- Powerful indexing, filtering, and grouping operations
- Simplifies data cleaning and preprocessing

### Common use cases
- Loading datasets
- Cleaning missing or inconsistent data
- Exploratory Data Analysis (EDA)

---

## Matplotlib

### What it is
**Matplotlib** is a data visualization library for Python.

### Why it is used
- Creating plots and charts to understand data
- Visualizing distributions, trends, and model results
- Debugging and validating ML models visually

### Common use cases
- Line plots, bar charts, histograms
- Scatter plots for regression and classification
- Visualizing training loss and accuracy

---

## Scikit-learn

### What it is
**Scikit-learn** is a high-level Machine Learning library focused on classical ML algorithms.

### Why it is used
- Simple and consistent API
- Large collection of well-tested ML algorithms
- Excellent tools for preprocessing and evaluation

### Common use cases
- Regression and classification models
- Clustering and dimensionality reduction
- Train-test split and cross-validation
- Metrics (accuracy, precision, recall, MSE, etc.)

### Examples of algorithms
- Linear & Logistic Regression
- K-Nearest Neighbors
- Decision Trees & Random Forests
- K-Means, PCA

---

## TensorFlow

### What it is
**TensorFlow** is a low-level and high-performance framework for numerical computation and Deep Learning.

### Why it is used
- Automatic differentiation
- GPU and TPU acceleration
- Scalable training for large models

### Common use cases
- Building and training deep neural networks
- Custom training loops
- Production-level ML systems

---

## Keras

### What it is
**Keras** is a high-level Deep Learning API built on top of TensorFlow.

### Why it is used
- Simplifies neural network development
- Clean and intuitive syntax
- Rapid prototyping of deep learning models

### Common use cases
- Fully connected neural networks
- Convolutional Neural Networks (CNNs)
- Recurrent Neural Networks (RNNs)
- Experimenting with deep learning architectures

---

## How These Libraries Work Together

A typical workflow looks like this:

1. **NumPy** → numerical operations and arrays  
2. **Pandas** → data loading, cleaning, and preprocessing  
3. **Matplotlib** → data visualization and analysis  
4. **Scikit-learn** → classical ML models and evaluation  
5. **TensorFlow + Keras** → deep learning models and training  

Each library solves a specific problem, and together they form a complete Machine Learning ecosystem.
