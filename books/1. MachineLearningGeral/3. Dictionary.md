# Machine Learning Dictionary

This section is a **Machine Learning Dictionary**, created to centralize and explain the **main terms, concepts, and vocabulary** used in Machine Learning and Data Science.

The goal is to make ML terminology **clear, accessible, and easy to reference**, whether you are a beginner or an experienced practitioner.

## What You Will Find Here

In this dictionary, you will find definitions related to:

- Machine Learning concepts
- Data Science terminology
- Models and algorithms
- Training and evaluation terms
- Optimization and loss functions
- Statistics and probability basics
- Data preprocessing and feature engineering
- Model evaluation metrics

## Organization

Terms are organized in a clear and structured way to allow easy navigation and quick lookup.

Each entry may include:
- A short definition
- Practical examples
- Related concepts
- Notes or common pitfalls

# DICTIONARY
## A
- Adam: A gradient option , presents in optimization part

## B
- Batch: A system (B) in machine learning, that do the models train once time 
- Boosting: A type of regression model

## C
- Classification: A system (A.1) that contains labeled data and classes values in the target

## F
- Feature: Other name to call the a column in data science 

## G
- Gradient: Part of system (E) that transform and update the parameters
- GridSearch: A non-gradient option presents in optimization part, responsible for find the best hyperparameters for few features (SKLEARN FUNCTION)

## H
- Hyperparameters: A part of systems (E) that determines the train ways 

## I
- Instancie: A system (C) that determine if the model will learning the data per approximation/neighbors

## L
- Label: The label feature in a dataset, with the target
- Learning Rate: a part presents in optimization part, that help the gradient descent for don't have problems, and find the best parameters

- Linear: A type of regression/classification model
- Loss-Functions: A part of system (E) that determines if the model in train set, are doing good or bab predictions

## M
- Machine Learning: A subset of artificial intelligence (AI) that enables systems to learn from data, identify patterns, and improve performance without explicit programming.
- Metrics: A part of system (E), that determine the accuracy of the model with the test set
- Module: A system (C) that determine if the model will learning the data with math functions

## P
- Parameters: A part of systems (E) that determines the function to learn the data 

## R
- RandomizerSearch: A non-gradient option presents on optimization part, responsible for find the best hyperparameters for lots of feature (SKLEARN FUNCTION)

- Regression: A system (A.1) that contains labeled data and numeric values in the target

## S
- Sample: A exemple in data set/A row in dataset
- SemiSupervizec:  machine learning approach that trains models using a small amount of labeled data paired with a large volume of unlabeled data
- SGD: A gradient option, presents on optimization part
- Supervized Learning: A machine learning approach that trains algorithms using labeled data—input-output pairs—to predict outcomes or classify data accurately

## O
- Optimization: A part of system (D) that update and transform the parameters/hyperparameters

## T
- Target:The value itself on a label
- Tree-Based: A type of regression/classification model

## U
- Unsupervisez Learnibng: a machine learning approach that analyzes and clusters unlabeled datasets to discover hidden patterns, structures, or relationships without human intervention
