
# Ensemble Methods

An **ensemble** is a technique where **multiple simple models (weak learners)** are combined to create **a stronger and more robust model**.

Instead of relying on a single model, ensembles **aggregate predictions from several models** to improve performance and generalization.

### Main Idea
> Many weak models working together can produce a strong prediction.

---

# Types of Ensembles
There are **three main ensemble strategies**:
1. **Bagging / Pasting**
2. **Boosting**
3. **Stacking**

Ensembles can also be categorized as:
- **Homogeneous Ensembles** → all models are the same type  
- **Heterogeneous Ensembles** → models are different types

---
# 1 BAGGING/PASTING
- The dataset was copied in N times for N models, and each copy some samples are selected for train each model.

## 1.1 Bagging (Bootstrap Aggregating)
Bagging creates **multiple copies of the dataset** and trains **independent models** on each copy.
Each model receives a **different random sample of the dataset**.

### Important Characteristics
- Sampling is done **with replacement**
- The same sample **can appear multiple times within a dataset copy**
- Different dataset copies **may also end up identical**
- Models are **independent** (training one model does not affect others)

### Example

```
Original dataset:
[A, B, C, D]

Sampled datasets:
[B, D, B, A] → Model A
[B, B, B, A] → Model B
[B, D, B, A] → Model C (same as Model A)

Notice:
- Samples can repeat inside the same dataset.
- Two models may receive identical datasets.
``` 

### Final Prediction
Predictions are usually combined by:
- **Voting** (classification)
- **Averaging** (regression)

### Example of Bagging Model
- Random Forest
Random Forest = Bagging applied to Decision Trees with additional feature randomness.

---
## 1.2 Pasting
Pasting is very similar to Bagging, but **sampling is done without replacement**.

### Key Difference
- **Bagging:** sampling **with replacement**
- **Pasting:** sampling **without replacement**

This means:
- No repeated samples inside each dataset copy.

### Example
```
Valid dataset copy:
[A, B, C, D]


Invalid dataset copy:
[A, B, C, D, D] ❌

The sample **D appears twice**, which is not allowed in Pasting.
```
