# Prerequisites for Gradient-Based and Non-Gradient Methods

After studying **gradient-based models**, it is important to understand that **there are other types of models in Machine Learning** that **do not rely on gradients or backpropagation** to learn.

These models use different learning strategies, such as:
- Logical rules (if/else)
- Search and combinatorial optimization
- Classical statistics
- Tree-based decisions
- Trial-and-error guided by metrics

Not every model updates weights using derivatives.

# How Models Learn (Overview)

## GENERAL WORKFLOW

**EACH MODEL HAS ITS OWN WAY OF LEARNING.**

There is no single workflow that applies to all Machine Learning models:

- Some use **gradients and derivatives**
- Some rely on **conditional splits (if/else)**
- Others use **heuristic or combinatorial search**
- Others combine **multiple weak models**

> All models use mathematics to produce results,  
> but **not all of them use gradients, backpropagation, or continuous weight updates**.

Because of this, it is essential to **study how each model learns individually**.


# EXAMPLES 
Models that **do not explicitly use gradients** for learning.

## Tree-Based Models
- Decision Trees
- Random Forests

## Support Vector Machines (Optimization-Based)
- Linear SVM
- Kernel SVM  
> Use convex optimization (Quadratic Programming), not backpropagation

## Rule-Based / Probabilistic Models
- Naive Bayes
- Rule-based systems

## Instance-Based Models
- K-Nearest Neighbors (KNN)

# Key Takeaways

- **Gradients are NOT mandatory for Machine Learning**
- Different models learn in fundamentally different ways
- Understanding *how* a model learns is as important as knowing *how* to use it
- There is no universal learning workflow

> Learning Machine Learning means learning **families of models**, not just techniques.
