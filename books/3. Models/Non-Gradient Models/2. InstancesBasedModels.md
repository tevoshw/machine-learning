# Instance-Based Models (K-Nearest Neighbors)
### (Lazy Learning, Distance-Based, Non-Gradient Models)

---

## Core Concept: No Training, No Gradients

**K-Nearest Neighbors (KNN) does NOT use Gradient Descent.**

It does not:
- Learn weights
- Optimize a loss function
- Build a parametric model
- Perform iterative updates

Instead, KNN is a **lazy, instance-based algorithm** that:
- Stores the training data
- Defers computation until prediction time
- Makes decisions based on **distance to known instances**

---

# 1. Instance-Based Learning

## 1.1 What Is Instance-Based Learning?

Instance-based models:
- Do not build an explicit model
- Memorize the training dataset
- Compare new samples directly against stored examples

Learning happens **at inference time**, not during training.

KNN is the most common instance-based algorithm.

---

# 2. K-Nearest Neighbors (KNN)

## 2.1 What Is KNN?

KNN predicts the output of a new data point by:
- Finding the **K closest samples** in the training set
- Aggregating their targets

Depending on the task:
- **Classification** → majority vote
- **Regression** → average of neighbors

---

## 2.2 How KNN Works (Workflow)

### Step-by-Step Process

1. **Store the training data**
   - No parameters are learned
   - Dataset is kept in memory

2. **Choose a distance metric**
   - Defines what “close” means
   - Common choices:
     - Euclidean
     - Manhattan
     - Minkowski
     - Cosine (for high-dimensional data)

3. **Receive a new query point**
   - Model is asked to make a prediction

4. **Compute distances**
   - Distance from query point to every training sample

5. **Select the K nearest neighbors**
   - Sort distances
   - Keep the K smallest ones

6. **Aggregate neighbors**
   - Classification: majority class
   - Regression: mean (or weighted mean)

---

## 2.3 Distance Metrics

### Euclidean Distance (Most Common)

Measures straight-line distance.

**Formula:**

$ d(x, y) = √Σ(xᵢ − yᵢ)²$


- Sensitive to feature scale
- Requires normalization

---

### Manhattan Distance

Measures distance along axes.

**Formula:**

$d(x, y) = Σ |xᵢ − yᵢ|$


- More robust to outliers
- Works well in high dimensions

---

## 2.4 Role of K

The value of **K** controls model behavior.

| K Value | Effect |
|------|-------|
| Small K | Low bias, high variance |
| Large K | Higher bias, lower variance |

- K = 1 → memorization
- Large K → smoother decision boundaries

> So the K in KNeighbors define the output, if we define 3, the 3 nearest values are used to get the output.

```
1. In regressor the output become the median of KNeighbors  
2. In classifier the output become the value which most appear in the KNeighbors
```

---

## 2.5 Weighting Neighbors

Neighbors can be:
- **Uniformly weighted**
- **Distance-weighted**

Distance weighting gives more importance to closer points.

---

# 3. KNN for Classification vs Regression

## 3.1 KNN Classifier

- Uses majority voting
- Can output class probabilities
- Sensitive to class imbalance

Prediction:

$ŷ = model(y₁, y₂, ..., yₖ)$


---

## 3.2 KNN Regressor

- Uses average of neighbor values
- Produces smooth predictions

Prediction:

$ŷ = (1 / K) Σ yᵢ$


---

# 4. Key Characteristics of KNN

### Strengths
- Simple and intuitive
- No training phase
- Non-parametric
- Naturally non-linear

### Weaknesses
- Very slow inference
- High memory usage
- Sensitive to feature scaling
- Curse of dimensionality

---

# 5. KNN vs Tree-Based Models

| Aspect | KNN | Trees / Forests |
|----|----|----|
| Uses Gradient Descent | No | No |
| Training Phase | None | Yes |
| Inference Speed | Slow | Fast |
| Memory Usage | High | Moderate |
| Interpretability | Medium | High (trees) |
| Feature Scaling | Required | Not required |

---

# 6. Key Takeaway

- **KNN is an instance-based, lazy learning algorithm**
- No gradients, no optimization, no parameters
- Predictions are made by **distance comparison**
- Performance depends heavily on:
  - Feature scaling
  - Distance metric
  - Choice of K

KNN learns by **remembering**, not by **optimizing**.
