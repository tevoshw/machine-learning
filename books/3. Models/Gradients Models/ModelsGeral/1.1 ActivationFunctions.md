# Activation Functions (The Forward Pass "Extra")

In Machine Learning classification, targets are represented as discrete numbers (e.g., Binary: `0, 1` or Multiclass: `1, 2, 3...N`). However, mathematical models naturally produce continuous raw numbers. Activation functions are the "translators" that convert these raw numbers into probabilities. The probabilities it's a number between 0-1, so 1 = 100% and 0 = 0%.

```
EXAMPLE:

We have 7 types of glasses, from 1-7, and the model need to predict them. However the y' it's 326

y' = f(x)
y' = 326 -> The loss function will receive this value and return a list of probabilities for each class

AF = 326 -> [0.1, 0.1, 0.1, 0.1, 0.58, 0.01, 0.01]
              1    2    3    4    5      6     7 

So here the higher % it's the class 5, with 58% of assurance 

```

> Only some models have ACTIVATIONS FUNCTIONS, so this isn't a law for ever model e.g. (classification problems and neural networks)

# Types

## 1. Sigmoid (Binary Classification)
Used in the output layer of binary models. It "squashes" any real-valued number into a range between **0 and 1**, representing the probability of the positive class.
$$\sigma(z) = \frac{1}{1 + e^{-z}}$$
* **Output:** $P \in [0, 1]$
* **Use Case:** Logistic Regression, Binary Neural Networks.


## 2. Softmax (Multiclass Classification)
The multiclass generalization of the Sigmoid. it takes a vector of raw scores (logits) and turns them into a probability distribution where the sum of all components is exactly **1.0 (100%)**.
$$\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}$$
* **Output:** A vector of probabilities $[P_1, P_2, ..., P_K]$.
* **Use Case:** Softmax Regression, XGBoost (multiclass), Deep Learning output layers.


## 3. ReLU - Rectified Linear Unit (Hidden Layers)
The most common activation for deep learning. It filters out negative values, which helps the model learn complex patterns without "vanishing" gradients. Unlike Sigmoid/Softmax, it is rarely used in the final classification output because its range is $[0, \infty)$.
$$f(z) = \max(0, z)$$
* **Output:** 0 for negative inputs, $z$ for positive inputs.
* **Use Case:** Hidden layers in Neural Networks (MLP, CNN).


## 4. Tanh - Hyperbolic Tangent
Similar to Sigmoid but ranges from **-1 to 1**. It is zero-centered, which often makes the optimization process (training) faster in certain neural network architectures.
$$\tanh(z) = \frac{e^{z} - e^{-z}}{e^{z} + e^{-z}}$$
* **Output:** $P \in [-1, 1]$
* **Use Case:** Recurrent Neural Networks (RNNs) and specific hidden layers.
