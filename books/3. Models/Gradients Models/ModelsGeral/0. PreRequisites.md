# Prerequisites for Gradient-Based Methods

For an optimization algorithm (such as **Gradient Descent**) to work, it's not enough to just have data. Structurally, the system needs fundamental pillars to enable learning:

## 1. Differentiable Parameters ($\theta$)
These are the internal variables that the model adjusts during training.
* **What they are:** Weights ($w$) and Biases ($b$).
* **Requirement:** They must be continuous numerical values. The gradient requires that small changes in the parameters generate predictable changes in the output.

## 2. Differentiable Loss Function ($L$)
The Loss Function quantifies the model's error.
* **What it does:** Measures the "distance" between the model's prediction ($y'$) and the actual value ($y$).
* **Mathematical Requirement:** The function must be **differentiable** (have a defined derivative). Without a derivative, we cannot calculate the "slope" necessary to know which direction to adjust the parameters.


# How the Model Learns (Overview)

Machine learning is essentially a mathematical optimization problem divided into four cyclic steps:

### A. Forward Pass
When we define a model, we establish a mathematical function to process data.
1. The model receives inputs ($x_1, x_2...x_n$).
2. It uses the current parameters ($w, b$) to calculate a prediction.
3. **Result:** The model returns an output value $y'$.
> For a deeper understanding: `ForwardPass.md`

### B. Loss Calculation
The model compares its prediction ($y'$) with the ground truth ($y$).
1. There are different types of losses (MSE, Cross-Entropy, etc.), each using different math functions to measure the error.
> For a deeper understanding: `LossFunction.md`

### C. Backpropagation
Once the loss is known, the model must identify how much each weight contributed to the error.
1. **Loss Landscape:** Imagine a multidimensional graph where the height is the loss. While the human brain can't visualize 50 dimensions, math can.
2. **Derivatives:** Using the **Chain Rule**, the model calculates the derivative for each parameter.
3. **The Gradient:** These derivatives form a vector (magnitude and direction) that tells the model how to transform the weights to reduce the error.
> For a deeper understanding: `OptimizationInternModel.md`

### D. Parameter Update
The model uses optimization functions to receive the gradient vector and update the weights.
1. Each complete cycle (Forward to Update) is called an **iteration**.
2. Training can involve anywhere from 10 to 1,000+ iterations.
> For a deeper understanding: part II in `OptimizationInternModel.md`

### Summary of the Optimization Flow

| Component | Role in the Algorithm | Analogy (Mountain Descent) |
| :--- | :--- | :--- |
| **Parameters ($\theta$)** | What is being optimized | Your GPS location on the mountain |
| **Loss Function ($L$)** | Target to be minimized | The altitude (you want to reach sea level) |
| **Gradient ($\nabla$)** | Direction of the adjustment | The slope of the ground under your feet |
