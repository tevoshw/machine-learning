# Prerequisites for Gradient-Based Methods

For an optimization algorithm (such as **Gradient Descent**) to work, it's not enough to just have data. Structurally, the system needs four fundamental pillars:

---

## 1. Differentiable Parameters ($\theta$)
These are the internal variables that the model adjusts to learn.
* **What they are:** Weights ($w$) and Bias ($b$).
* **Requirement:** They must be continuous and numerical values. The gradient requires that small changes in the parameters generate predictable changes in the output.

## 2. Differentiable Loss Function ($L$)
The Loss Function quantifies the model error.
**What it does:** Measures the distance between the model's prediction and the actual value.
**Mathematical Requirement:** The function must be differentiable (have a derivative). Without a defined derivative, we cannot calculate the necessary "slope" to know where to adjust the parameters.

## 3. Gradient ($\nabla L$)
It is the optimizer's compass.
**Definition:** A vector of partial derivatives that indicates the direction of greatest rise in the loss function.
**Application:** The gradient-based method moves the parameters in the **opposite** direction to the gradient to minimize the error.

## 4. Learning Rate ($\alpha$ or $\eta$)
The Learning Rate is the hyperparameter that controls the magnitude of the adjustment.
* **Function:** Determines the size of the "step" taken in each iteration.
* **Importance:** * If too high: The model may "skip" the minimum error point and diverge.
* If too low: Training will be extremely slow and may get stuck in local minima.

### Summary of the Optimization Flow

| Component | Role in the Algorithm | Analogy (Mountain Descent) |
| :--- | :--- | :--- |
| **Parameters** | What should be optimized | Your GPS location on the mountain |
| **Loss Function** | Target to be minimized | The altitude (you want to reach sea level) |
| **Gradient** | Direction of adjustment | The slope of the ground under your feet |

| **Learning Rate** | Descent speed | The length of your stride |

$$\theta_{next} = \theta_{current} - \alpha \cdot \nabla L(\theta)$$
