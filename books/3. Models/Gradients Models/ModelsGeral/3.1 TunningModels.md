# MODEL TUNING & OPTIMIZATION

## Introduction
Model Tuning is the architectural refinement of a Machine Learning system. It is the process of moving beyond default settings to find the "Sweet Spot" between a model that is too simple (**Underfitting**) and one that is too complex (**Overfitting**). 

Instead of just "running a model," Tuning is an engineering workflow used to maximize specific performance metrics—such as **Recall** for safety-critical tasks—by optimizing how the model sees the data and how its internal mathematical engine operates.

### 1.3 SPLIT METHODS (Validation Strategies)
Instead of a single "final exam" (simple Train/Test), you perform several "simulated tests" by rotating the data. This ensures the model actually learned the patterns rather than just memorizing the answers (overfitting).

* **WHY USE IT?**
1. **Robustness:** Ensures performance wasn't just "luck" from a single favorable data split.
2. **Stability Measurement:** Allows you to calculate the Standard Deviation; if accuracy varies wildly between splits, the model is unstable.

**TYPES**
1. **K-Fold:** Divides the dataset into $K$ fixed blocks (folds). Each block serves as the test set once, while the others are used for training.
    * **Rule:** Every single data point is tested exactly once.
    * **Best for:** Small to medium-sized datasets. | `KFold()` |
    

2. **ShuffleSplit:** Performs random and independent shuffles/draws for each round, without being tied to fixed blocks.
    * **Rule:** There may be overlap (a data point might be tested multiple times or not at all).
    * **Best for:** Very large datasets (Big Data). | `ShuffleSplit()` |
    

3. **Stratified (Classification Version):** A "safety lock" applied to K-Fold or Shuffle.
    * **What it does:** Ensures each split maintains the same class proportions (e.g., 10% of each digit in MNIST).
    * **Best for:** **Mandatory for Classification tasks.** | `StratifiedKFold()` | `StratifiedShuffleSplit()` |
    

4. **Time Series Split:** A chronological split where the past trains the future.
    * **What it does:** The training window grows with each round, and the test set is always the subsequent time block. Prevents **Data Leakage**.
    * **Best for:** Stock prices, weather, and sales forecasting. | `TimeSeriesSplit()` |
