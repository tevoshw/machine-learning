# 0. Review: Machine Learning Fundamentals
 
## Overview
In machine learning, our primary objective differs based on the problem type, but the underlying principle remains consistent: **find optimal decision boundaries or functions that best represent the data**.
 
## Regression: Finding the Best Fit Line
 
In **regression**, our goal is to:
- Define one or more continuous functions that map input features to continuous output values
- **Minimize the distance** between the actual data points and our predicted line/curve
- This distance is typically measured using metrics like:
  - **Mean Squared Error (MSE)**: average of squared residuals
  - **Mean Absolute Error (MAE)**: average absolute difference
  - **Root Mean Squared Error (RMSE)**: square root of MSE
 
The optimal line is the one that minimizes these distance measurements across all training data points.

## Classification: Separating Classes
 
In **classification**, our goal is to:
- Define **decision boundaries** that separate different classes in the feature space
- Assign new, unseen data points to the correct class based on these boundaries
- Minimize **classification error** (misclassified samples)
 
Common approaches include:
- **Linear boundaries** (e.g., logistic regression, SVM with linear kernel)
- **Non-linear boundaries** (e.g., neural networks, SVM with RBF kernel)

# The Main Objective

How we see a lot of different models, it's important to understand that there are two fundamental paradigms in machine learning: models that rely on gradient-based optimization and those that use non-gradient approaches.

And in this part we only gonna see 

* **NON-GRADIENT MODELS**

## What Are Non-Gradient Models?
Non-gradient models do NOT use derivatives to optimize. Instead, they use alternative strategies:

Tree-based partitioning: Recursively split the feature space
Distance-based decisions: Find nearest neighbors
Probabilistic inference: Use Bayes' theorem
Ensemble voting: Combine multiple weak learners

## How they work:
They find optimal splits or patterns through exhaustive search, information gain, distance metrics, or probabilistic measures
NO iterative gradient descent
NO need to compute derivatives

### Key Takeaways

- **Gradients are NOT mandatory for Machine Learning**
- Different models learn in fundamentally different ways
- Understanding *how* a model learns is as important as knowing *how* to use it
- There is no universal learning workflow

> Learning Machine Learning means learning **families of models**, not just techniques.
