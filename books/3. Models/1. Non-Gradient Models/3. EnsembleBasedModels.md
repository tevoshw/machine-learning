
# Ensemble Methods

## Non-Gradient Core Concept: No Gradients Involved

**Decision Trees and Random Forests do NOT use Gradient Descent.**

They do not:
- Compute gradients
- Optimize a global loss via calculus
- Update weights iteratively

Instead, they are **greedy, rule-based algorithms** that:
- Split the feature space step by step
- Optimize **local impurity metrics**
- Build decision rules in the form of *if–then* statements



---

# Types of Ensembles
There are **three main ensemble strategies**:
1. **Bagging / Pasting**
2. **Boosting**
3. **Stacking**

Ensembles can also be categorized as:
- **Homogeneous Ensembles** → all models are the same type  
- **Heterogeneous Ensembles** → models are different types

---
# 1 BAGGING/PASTING
- The dataset was copied in N times for N models, and each copy some samples are selected for train each model.

## 1.1 Bagging (Bootstrap Aggregating)
Bagging creates **multiple copies of the dataset** and trains **independent models** on each copy.
Each model receives a **different random sample of the dataset**.

### Important Characteristics
- Sampling is done **with replacement**
- The same sample **can appear multiple times within a dataset copy**
- Different dataset copies **may also end up identical**
- Models are **independent** (training one model does not affect others)

### Example

```
Original dataset:
[A, B, C, D]

Sampled datasets:
[B, D, B, A] → Model A
[B, B, B, A] → Model B
[B, D, B, A] → Model C (same as Model A)

Notice:
- Samples can repeat inside the same dataset.
- Two models may receive identical datasets.
``` 

### Final Prediction
Predictions are usually combined by:
- **Voting** (classification)
- **Averaging** (regression)

### Example of Bagging Model
- Random Forest
Random Forest = Bagging applied to Decision Trees with additional feature randomness.

---
## 1.2 Pasting
Pasting is very similar to Bagging, but **sampling is done without replacement**.

### Key Difference
- **Bagging:** sampling **with replacement**
- **Pasting:** sampling **without replacement**

This means:
- No repeated samples inside each dataset copy.

### Example
```
Valid dataset copy:
[A, B, C, D]


Invalid dataset copy:
[A, B, C, D, D] ❌

The sample **D appears twice**, which is not allowed in Pasting.
```

# 2 BOOSTING

Boosting is a **Sequential Ensemble** strategy. Instead of creating independent trees and averaging them (like Bagging/Random Forest), Boosting builds trees one after another. A new tree only exists to solve the "stupidity" (errors) of the previous one.

---

## 1. Detailed Workflow (Step-by-Step)

The core of Boosting is **Residual Optimization**. The model doesn't try to hit the target $y$ perfectly at once; it crawls toward it iteration by iteration.

1. **Initial Prediction ($F_0$):** The model starts with a "lazy" guess.
   * **Regression:** Starts with the mean of all $y$ values.
   * **Classification:** Starts with the log-odds of the classes.
2. **Calculate the Error (Residual):**
   * **Non-Gradient Models:** Error is the raw distance ($y - y'$).
   * **Gradient Models:** Error is the **Gradient of the Loss Function**. We calculate the derivative of the loss to know which direction to "push" the model to reduce the error fastest.
3. **The New Tree ($h_m$):** A new tree is created. Its **Target** is NOT the original classes, but the **Residuals** (the error left behind). It learns rules to correct what the previous tree missed.
4. **Update with Shrinkage (Learning Rate):** Instead of adding the full correction, we add only a fraction ($\eta$) to prevent the model from learning "noise" (overfitting).
   
**The Additive Formula:**
$$F(x) = \text{Tree}_1 + (\eta \cdot \text{Tree}_2) + (\eta \cdot \text{Tree}_3) \dots$$

---

## 2. Core Characteristics

* **Sequential Learning:** Trees have a hierarchy. Tree 10 is built specifically to fix the residual error of Tree 9.
* **Bias vs Variance Trade-off:** Boosting is a master at reducing **Bias**. If your model is too simple (Underfitting), Boosting adds complexity until it captures the patterns.
* **Early Stopping:** Since it adds trees sequentially, we can stop training as soon as the validation error stops dropping, preventing the model from "memorizing" the training data.
* **Stochastic Boosting:** Trees can be trained on a subset of data (subsample), introducing randomness that makes the model more robust.

---

## 3. Examples, the "Big Three"

### 1. AdaBoost (Adaptive Boosting)
* **Philosophy:** "Hard-to-classify samples should be prioritized."
* **Mathematical Approach:** Uses **Exponential Loss**. It increases the weights ($w_i$) of misclassified instances.
* **Limitation:** Very sensitive to **outliers** and noisy data because it tries to fit them aggressively.



### 2. XGBoost (Extreme Gradient Boosting)
* **Philosophy:** "Efficiency through Hardware and Regularization."
* **Regularization:** Adds a penalty term to the objective function:
    $$\Omega(f) = \gamma T + \frac{1}{2} \lambda \|w\|^2 + \alpha \|w\|$$
    * **$\gamma$:** Minimum loss reduction required to split a leaf.
    * **$\lambda$ (L2):** Smooths the weights to avoid extreme values.
    * **$\alpha$ (L1):** Promotes sparsity (feature selection).
* **Tree Discovery:** Uses a **Level-wise** growth (Breadth-First). It is robust but can be slower than Leaf-wise.



### 3. LightGBM (Light Gradient Boosting Machine)
* **Philosophy:** "Optimization for Large Scale Data."
* **Key Innovations:**
    * **GOSS (Gradient-based One-Side Sampling):** Keeps instances with large gradients and randomly samples instances with small gradients.
    * **EFB (Exclusive Feature Bundling):** Merges mutually exclusive features to reduce dimensionality.
* **Growth:** **Leaf-wise** (Depth-First). It splits the leaf that provides the maximum gain, potentially creating very deep, imbalanced trees.

---

#### Key Hyperparameters for Tuning

| Parameter | Purpose | High Value Impact |
| :--- | :--- | :--- |
| `n_estimators` | Number of trees | Risk of Overfitting |
| `learning_rate`| Weight of each tree | Needs more trees if low |
| `max_depth` | Depth of trees | Captures more patterns / Overfitting |
| `subsample` | % of data per tree | Prevents Overfitting (Stochastic) |
| `colsample_bytree` | % of features per tree | Similar to Random Forest feature sampling |

---

#### When to use what?
* **Small Data / Stability:** XGBoost.
* **Big Data / Speed / RAM constraints:** LightGBM.
* **Baseline / Simple Categorical:** AdaBoost.
* **Categorical Features without Encoding:** CatBoost (the 4th hidden king).
