# TREE-BASED-MODELS

## Non-Gradient Core Concept: No Gradients Involved

**Decision Trees and Random Forests do NOT use Gradient Descent.**

They do not:
- Compute gradients
- Optimize a global loss via calculus
- Update weights iteratively

Instead, they are **greedy, rule-based algorithms** that:
- Split the feature space step by step
- Optimize **local impurity metrics**
- Build decision rules in the form of *if–then* statements


# 1. Decision Trees

## 1.1 What Is a Decision Tree?
Decision trees are one of the most intuitive and powerful models in machine learning. They function like a flowchart of "yes or no" questions that lead to a final decision.


Imagine you're deciding whether to go to the beach:

1. Is it raining? If yes, I'll stay home.
2. If not, is it too windy? If yes, I'll stay home.
3. If not, I'll go to the beach.
### The Concept of Purity, Entropy, and Information Gain
Imagine you have a bucket with 50 red balls and 50 blue balls (total mixing = maximum entropy) and (total mixing = minimum purity).

If a question divides this into two buckets, one with 50 red balls and the other with 50 blue balls, this division is perfect, that is, (no mixing = maximum purity) and (no mixing = minimum entropy).

Information Gain is the result of $IGain = EntropyBefore - EntropyAfter$.

In Summary:
1. Entropy: How messy the data is after the question (0 = not messy, 1 = very messy).
2. Purity: How clean the data is after the question (0 = not clean, 1 = very clean).
3. Information Gain: The difference in how messy the data is before and after the question (node).

> Decision trees are better for problems of Classification, because dividing data into buckets with numbers is difficult.

### The Metrics of Purity

* **Entropy:** It measures disorder or uncertainty.
   1. If Entropy is 0: Absolute certainty. All data are of the same class.
   2. If Entropy is 1: Total confusion. The data are divided exactly in half (50/50).
   3. The calculation: It uses logarithms (it's a bit more "heavy" for the computer to calculate).

* **Gini:** It measures impurity (the chance of you choosing a die and misclassifying it).

   1. If Gini is 0: Total purity. Zero chance of error.

   2. If Gini is 0.5: Maximum impurity. You have a 50% chance of being wrong (in a two-class problem).

   3. The calculation: It uses the square of the proportions. It's much faster for the computer to process than Entropy.

> You choose one or the other in your model. They are like Celsius and Fahrenheit: two different scales to measure the same "temperature" (the disorder of the data).

## 1.2 The Architecture of a Decision Tree

* **Root Node:** It's the top of the tree, where the first question is asked the most important characteristic of your dataset.
   - Root Node (the first and most important question): The decision tree performs a kind of "beauty contest" among all the variables (columns) of your data. It tests each one to see which one best separates the data into homogeneous groups, that is, which one will have the greatest purity.
* **Internal Nodes:** These are the intermediate nodes that represent division rules based on attributes.
* **Branches**: The lines that connect the nodes, representing the result of a test (e.g., True or False).
* **Leaves**: These are the endpoints. Here there are no more questions, only the final result or prediction.

> For better visualization see:  https://mlu-explain.github.io/decision-tree

## 1.3 How a Decision Tree Works (Workflow)

### Step-by-Step Process

1. **Select a feature**
   - The model evaluates every available feature
   - For each feature, it tests multiple possible split points

2. **Split the dataset (Choose the IF/ELSE questions)**
   - Data is divided into left/right branches
   - Each branch becomes a new 
   
3. **Evaluate split quality using Gini or Entropy**
   - Each candidate split is scored
   - The split that best separates the data is chosen

4. **Repeat recursively**
   - The same process is applied to each node
   - Stops when a stopping condition is met:
     - Maximum depth
     - Minimum samples
     - Pure node



> So a **NODE** it's a point that take a decision, have leafs, and **LEAFS** and the results of that (the end of the tree)


## 1.4 Key Characteristics of Decision Trees

- Non-linear by nature
- No feature scaling required
- Highly interpretable
- **High variance → prone to overfitting**
- Greedy and locally optimal

**Each question create a line in the space that divide the data, when the nodes are completed, we can create shapes like circles, squares and more, see more in: https://www.researchgate.net/figure/Partitioning-of-an-input-space-by-a-decision-tree_fig1_228587781**

## 2.1 What Is a Random Forest?

A Random Forest is an **ensemble of many Decision Trees**.

Each tree:
- Is trained independently
- Sees different data
- Uses different features

Final prediction is obtained by:
- **Majority voting** (classification)
- **Averaging** (regression)

---

## 2.2 How a Random Forest Works (Workflow)

### Step-by-Step Process

1. **Bootstrap sampling (rows)**
   - Each tree is trained on a random sample of the dataset
   - Sampling is done *with replacement*

2. **Random feature selection (columns)**
   - At each split, only a subset of features is considered
   - Prevents trees from becoming too similar

3. **Train individual decision trees**
   - Each tree follows the standard decision tree workflow
   - Trees are usually grown deep (low bias)

4. **Aggregate predictions**
   - Classification: majority vote or probability average
   - Regression: mean of all tree outputs

---

## 2.3 Why Random Forests Work So Well

Random Forests reduce **variance**, not bias.

They work because:
- Trees are **decorrelated**
- Errors cancel out when averaged
- Overfitting of individual trees is reduced

This is a practical application of the **law of large numbers**.

---

## 2.4 Key Characteristics of Random Forests

- No gradients
- No global optimization
- Strong generalization
- Robust to noise
- Less interpretable than a single tree
- Excellent default for tabular data

## 3. Decision Trees vs Random Forests

| Aspect | Decision Tree | Random Forest |
|-----|--------------|--------------|
| Uses Gradient Descent | No | No |
| Model Type | Single model | Ensemble |
| Bias | Low | Slightly higher |
| Variance | High | Low |
| Overfitting | Very likely | Controlled |
| Interpretability | High | Medium |
| Stability | Low | High |

---

## 4. Key Takeaway

- **Decision Trees and Random Forests are NOT gradient-based models**
- They rely on **greedy splits and impurity metrics**
- Random Forests improve performance by combining many weak trees
- Both models learn by **partitioning the feature space**, not by optimizing a differentiable loss
