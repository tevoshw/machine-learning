# Support Vector Machines (SVM)
## Non-Gradient Core Concept: Margin Maximization

**Classic SVMs do NOT use Gradient Descent.**

They do not:
- Update weights bit-by-bit like a Neural Network
- Minimize a smooth loss via simple calculus
- Iterate through epochs to find a global minimum

Instead, SVM is a **geometric optimization algorithm** that:
- Seeks the **hyperplane** (boundary) that best separates classes
- Maximizes the **margin** (distance) between the data and the boundary
- Resolves a **Quadratic Programming** problem

> In resume: SVM tries to build the widest "road" possible between two cities (classes).


# 1. Linear Support Vector Machines

## 1.1 What Is SVM?

SVM is a model that searches for a line (in 2D) or a plane (in 3D) that divides data perfectly.
- **Decision Boundary:** The line separating the classes.
- **Margin:** The distance between the boundary and the closest points of each class.
- **Hard Margin:** Does not allow errors (data must be perfectly separable).
- **Soft Margin:** Allows some misclassifications to maintain a wider margin (controlled by the **C** parameter).


# 2. Key Components

## 2.1 Support Vectors
These are the data points located **exactly on the edge of the margin**.
- They are the only points that "support" the boundary.
- If you remove any other point from the training set, the model stays the same.
- If you move a Support Vector, the boundary must change.

## 2.2 The Hyperplane
The generalization of a "line" for many dimensions. In an $n$-dimensional space, the hyperplane has $n-1$ dimensions.

# 3. The Kernel Trick

## 3.1 Solving Non-Linear Data
When data cannot be separated by a straight line (e.g., a circle of points inside a ring), SVM uses **Kernels**.

**The Process:**
1. Maps data into a higher dimension (e.g., from 2D to 3D).
2. Finds a straight hyperplane in this new dimension.
3. When projected back to the original space, the cut appears as a curve or circle.

**Common Kernels:**
- **Linear:** For data already separable by a line.
- **RBF (Radial Basis Function):** Creates circular/complex boundaries (the most common).
- **Polynomial:** Creates curved boundaries based on polynomials.


# 4. Useful Parameters (Hyperparameters)

| Parameter | Function | Effect |
| :--- | :--- | :--- |
| **C** | Controls the penalty for misclassification. | **Low C:** Wide margin, accepts errors (low overfitting). <br> **High C:** Narrow margin, tries to classify everything correctly (high overfitting). |
| **Gamma** | Defines the influence of a single point (for RBF). | **High Gamma:** Only nearby points matter (complex boundary). <br> **Low Gamma:** Distant points also influence (smooth boundary). |


# 5. SVM for Classification vs Regression

## 5.1 SVC (Classifier)
Tries to keep the maximum number of points outside the margin (separated).

## 5.2 SVR (Regressor)
Inverts the logic: tries to fit as many points as possible **inside** the margin. The center line is the prediction, and the margin represents the acceptable error limit ($\epsilon$).

# 6. Key Characteristics of SVM

### Strengths
- Highly effective in high-dimensional spaces (many features).
- Robust against Outliers (focuses only on critical support vectors).
- Versatile due to different Kernel functions.

### Weaknesses
- **Slow Training:** Becomes computationally expensive for very large datasets (>100k rows).
- **Sensitive to Scaling:** Requires Normalization/Standardization (like KNN).
- **Black Box:** Hard to interpret why specific non-linear boundaries were chosen.

# 7. Key Takeaway

- **SVM is a boundary-based, margin-maximizing algorithm.**
- It ignores "easy" points and focuses on the **Support Vectors**.
- Uses the **Kernel Trick** to solve complex, non-linear problems.
- Performance depends heavily on **Feature Scaling** and the **C parameter**.

SVM learns by **finding the widest gap**, not by **voting** or **splitting rules**.
